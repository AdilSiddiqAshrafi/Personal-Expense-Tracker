**Personal-Expense-Tracker**

  [Live Demo](https://adilexpensetracker.kesug.com/)

A fully responsive and dynamic Personal Expense Tracker built using PHP, MySQL, JavaScript (ES6+), and Bootstrap 5, designed to provide users with real-time financial tracking, insights, and secure data management.

**Core Features**

* Secure user authentication system with session-based login & password hashing
* Interactive dashboard showing:
Total balance
Total income
Total expenses
* Last 5 recent transactions
*  Complete Income & Expense management system with CRUD operations
* Category-based transaction system for structured financial tracking
* Live Search functionality for instant filtering of transactions (no page reload)
* Category-wise filtering (view transactions by selected category)
* Monthly financial reporting system

**Advanced Analytics & Reporting**

* Top 5 highest expense transactions
* Lowest spending analysis
* Category-wise spending summary
* Transaction count per category
* Spending pattern insights for better financial decisions

**Dynamic API-Based System**
* Real-time updates using AJAX / API calls
* Asynchronous JavaScript using async/await
* Fully dynamic UI updates without page refresh
* Smooth frontend-backend communication

**Security Features**

* Password hashing for secure authentication
* Session-based access control
* User-specific data isolation (each user sees only their own data)
* Protected routes for authorized access

**Technical Highlights**

* Full-stack architecture (Frontend + Backend + Database)
* Object-Oriented Programming (OOP) in PHP
* PDO (PHP Data Objects) for secure database interaction
* REST-like API communication
* Modular and clean code structure
* Optimized MySQL queries for reporting
* Responsive UI using Bootstrap 5
